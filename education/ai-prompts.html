Class 1

Basics of AI and Effective Prompting

Clarifying questions first
Before you answer, ask me the 3 most important clarifying questions. After I reply, give your full response.
Step-by-step reasoning
Think step by step.
1. Restate the problem and list the constraints.
2. Outline 2–3 possible approaches.
3. Recommend one approach and explain why.
4. Provide the solution.
Strict JSON format
Respond only with valid JSON using exactly these keys: "summary", "key_points", "risks", "next_actions". No other text.
Audience + length control
Explain [topic] to a [audience level]. Use no more than [N] words. Include one analogy and one concrete example.

Class 2

Brainstorming with AI

Quantity first
Generate 15 unconventional ideas for [problem or opportunity]. Prioritize novelty over immediate practicality. For each idea give a one-sentence description and one potential benefit.
SCAMPER
Apply the SCAMPER technique to this concept: [idea].
For each of the seven letters (Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse) produce two concrete variations.
Perspective shifting
Analyze this idea from three viewpoints:
1. A skeptical buyer with budget authority
2. A first-time user with no domain knowledge
3. A competitor looking for weaknesses
For each viewpoint list 3 concerns and 2 opportunities.
Seed expansion
Take this seed idea: [paste]. Expand it in three directions:
1. Minimal viable version
2. Ambitious full vision
3. Adjacent opportunity that solves a related problem
For each, state the target user, core value proposition, and key differentiator.
Riskiest assumption
Here is my current idea: [paste].
Identify the single riskiest assumption. Then propose the smallest, fastest experiment that would test that assumption.

Class 3

Leveraging Multiple AIs

Master meta-prompt (ChatGPT → Grok requirements)
I have been developing this idea with you: [paste developed idea or clear summary]

Please create a single, lean, and highly structured prompt that I can copy and paste into Grok to generate professional software requirements.

The prompt you create must:
- Be concise — no unnecessary preamble or fluff
- Instruct Grok to act as an expert product manager and technical architect
- Request exactly these sections:
  1. Executive Summary (3–5 sentences)
  2. User Personas (2–3)
  3. Functional Requirements (numbered user stories with acceptance criteria)
  4. Non-Functional Requirements (performance, security, scalability, reliability, etc.)
  5. Technical Constraints and Assumptions
  6. Out of Scope
  7. Open Questions
- Emphasize precision, completeness, and developer-readiness
- Tell Grok to flag any ambiguities or missing information explicitly
- Output the finished prompt inside a clean code block so it is easy to copy

Make the prompt as tight and effective as possible.
Edge-case discovery
Review the requirements. List the 10 most important edge cases or failure modes that are not adequately covered. For each, suggest how it should be handled.
